# Wake Word Roadmap

A Jarvis wake word on the HUD is proposed, not built. Candidates named in the spec are Picovoice Porcupine or openWakeWord on the server, so a dedicated screen would not need a tap. Browsers would still fall back to a tap.

This is separate from Mickey's on-device ESP-SR wake word. See [[Wake Word and Boot Button]] and [[Voice Roadmap]].
