# Desk Roles

Roles named in the runbook are ceo, sysadmin, researcher, deep_researcher, business_manager, and secretary. Voice on the HUD runs as ceo with delegation tools removed. Telegram can still use the researcher path.

Tools declare an owner role. Execution checks that role, not only the declaration. Custom skills default to ceo. Web search is visible to the voice ceo so a news question does not have to leave the speaker. See [[Voice Cannot Delegate]] and [[Secretary Front Desk]].
