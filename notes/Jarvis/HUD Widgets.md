# HUD Widgets

`show_hologram` opens a draggable popup. Live widgets are map, weather, schedule, tasks, system vitals, report, and image. Weather comes from wttr.in. System vitals come from psutil. Schedule lists APScheduler jobs. Tasks list ongoing items from memory.

The popup close button is 28 pixels so a finger can hit it. Dragging the header ignores taps on that button. Say "show my schedules", "what tasks are ongoing", or "system vitals" and the card appears while Jarvis speaks. See [[Voice Tool Loop]] and [[Scheduler]].
