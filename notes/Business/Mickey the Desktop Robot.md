# Mickey the Desktop Robot

Mickey is an ESP32-S3 desktop AI robot in the style of an EMO desk companion. It uses the open-source XiaoZhi client for voice, networking, display, and device control. It must not copy LivingAI firmware, assets, branding, cloud APIs, or industrial design.

The board profile is `mickey`: no camera on the main chip, no hands, four servos. Personality is face, body, and voice. See [[Mickey Board Identity]] and [[No Hands Four Servos]].
