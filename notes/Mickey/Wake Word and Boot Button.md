# Wake Word and Boot Button

On the device today, wake word is ESP-SR AFE with the `wn9_nihaoxiaozhi_tts` model. GPIO 0 toggles chat. A click during `kDeviceStateStarting` enters Wi-Fi config. There is no idle long-press to re-pair.

A later spec phase mentions MultiNet phrases for Mickey, Hey Mickey, and Hi Mickey, including Burmese-accented syllables. That phrase set is not what the August production note says is already running. See [[Wi-Fi First Boot]] and [[Audio Path]].
