# Vision Reflex Table

Reflexes are local and have no hands. An unknown person entering gets a curious or surprised face and a small sway. A known face, slots 0 to 4, gets that person's emotion clip. Gaze holds eye contact and pauses idle fidget. A wave from the user gets a happy face and a swing or a reduced walk, never a hand wave. Leave returns to idle with a soft sad or static face. A phone in view gets an ignored or embarrassed look.

The perceived budget is under 200 milliseconds with the WebSocket closed. Scene classes are a closed set: none, present, approach, leave, gaze, wave, phone, unknown. Open-ended questions go to the companion vision model only when asked. See [[No Hands Four Servos]] and [[Face ID Five Slots]].
